# Makes Python verify TLS against the Windows certificate store instead of
# certifi's bundled list. Required on the corporate network: the proxy re-signs
# HTTPS with an internal root that is trusted by Windows and absent from certifi,
# so without this every request to gis.nationalgrid.com fails with
#   SSLCertVerificationError: self-signed certificate in certificate chain
# auth.make_session() injects it when it is importable and warns when it is not.
truststore>=0.9; python_version >= "3.10"

# The enterprise (Maximo) leaks come from a SQL database rather than from the
# ArcGIS service, and pyodbc is how scripts/maximo_leaks.py reaches it. Optional
# because nothing else needs it: python run.py, the map and the dashboards all
# work without it, and maximo_sql imports it only at the moment it connects, so
# a machine without an ODBC driver still runs the rest of the project and its
# tests. It also needs a driver installed - "ODBC Driver 18 for SQL Server".
#
# Any DB-API 2.0 connection works, so another driver (oracledb, for instance)
# can be handed to maximo_sql.read_leaks(connection=...) instead.
pyodbc>=5.0
